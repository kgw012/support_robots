# 🤖 서포트 로봇 (Support Robots)

> **무너지는 지하 폐기장, 최소한의 지반 충격으로 고장 난 로봇들을 탈출시켜라!**  
> 알렉스 랜돌프(Alex Randolph)의 보드게임 **《리코셰 로봇(Ricochet Robots)》**을 원작(영감)으로 하여, 고유 규칙인 **'유압식 충격 흡수(로봇 간 완충 충돌)'** 시스템을 결합해 자체 제작한 비영리 웹 퍼즐 게임입니다.

---

## 📖 세계관 및 핵심 규칙

버려진 로봇 공장의 지하 폐기장이 붕괴하기 시작했습니다. 자세 제어 장치와 마찰력을 상실한 로봇들은 한 번 미끄러지면 **벽이나 다른 로봇에 부딪히기 전까지 스스로 멈출 수 없습니다.**

1. **직선 슬라이딩 기동**
   * 선택한 로봇을 상·하·좌·우로 스와이프(또는 드래그/방향키 입력)하면 장애물(외벽, 내부 벽, 중앙 폐쇄 구역, 다른 로봇)을 만날 때까지 끝까지 미끄러집니다.
2. **목표 탈출구 매칭 & 방향 전환(Ricochet) 필수 규칙**
   * 목표 탈출구와 **같은 색상의 로봇**을 해당 위치에 정지시켜야 합니다 (다색 탈출구는 모든 로봇 가능).
   * 출발지에서 목표 지점까지 한 번에 직진으로 도달하는 것은 무효이며, **최소 1회 이상 벽이나 로봇에 부딪혀 90도로 방향을 꺾은(Ricochet) 후 도달**해야 탈출로 인정됩니다.
3. **지반 충격 최소화 & 로봇 간 완충(Shock Absorber) 타이 브레이커**
   * **우선순위 1 (최소 이동):** 이동 횟수가 적을수록 지반 진동을 최소화한 우수한 기록으로 판정합니다.
   * **우선순위 2 (최다 완충):** 이동 횟수가 같다면, 단단한 콘크리트 벽 대신 **다른 로봇에 부딪혀 유압 완충 장치로 충격을 흡수·분산시킨 횟수(`완충`)가 많을수록** 더 높은 기록으로 인정받습니다.

## ✨ 주요 기능

* **원작 8x8 사분면 보드 4개 랜덤 조합 엔진:** 4개의 8x8 보드 타일이 매 라운드 무작위 위치·회전으로 결합되어 16x16 보드를 구성합니다.
* **모바일 친화적 터치 & 엄지 조작 UI:** 로봇 위에서 바로 스와이프하여 선택+이동을 동시에 수행할 수 있으며, 하단 좌·우에 `처음부터(Reset)`와 `되돌리기(Undo)`를 배치했습니다.
* **초고속 BFS 자동 맵 솔버 & 난이도 자동 분류:**
  * 너비 우선 탐색(BFS)으로 현재 맵의 **최단 이동 횟수**와 **최적 완충 횟수**를 실시간 연산합니다.
  * 최단 해결 횟수에 따라 난이도를 자동 분류합니다: `EASY (1~4회)`, `HARD (5~9회)`, `HELL (10회 이상)`.
  * 클리어 시 정답 경로를 직접 노출하지 않고, **이동을 더 줄일 수 있는지** 혹은 **완충을 더 늘릴 수 있는지** 단계별 힌트만 제공합니다.

## 🛠️ 기술 스택

* **Frontend:** HTML5, Vanilla CSS (CSS Grid 16x16), Modern Vanilla JavaScript (ES Modules)
* **Backend / Leaderboard (Phase 3 예정):** Supabase (PostgreSQL)

## 📂 디렉터리 구조

```text
support_robots/
├── index.html          # 메인 게임 화면 (16x16 보드 및 HUD)
├── css/
│   └── style.css       # 반응형 모바일 그리드 및 로봇/타깃 스타일
└── js/
    ├── boardPresets.js # 8x8 사분면 타일 4종 비트마스크 프리셋 및 회전 조합기
    ├── state.js        # 라운드 상태 및 Undo/Reset/최고기록 관리
    ├── physics.js      # 직선 슬라이딩 물리 엔진 및 벽/로봇 충돌 판정
    ├── input.js        # 모바일 터치 스와이프 및 마우스/키보드 입력 캡처
    ├── rules.js        # 색상 매칭 및 90도 방향 전환(Ricochet) 필수 규칙 판정
    ├── solver.js       # BFS 최단 경로·최대 완충 솔버 및 난이도 분류기
    ├── renderer.js     # CSS Grid 및 인라인 SVG 렌더링 모듈
    └── main.js         # 앱 진입점 및 이벤트 바인딩
```

## 🚀 로컬 실행 방법

별도의 빌드 도구 없이 정적 웹 서버로 바로 실행할 수 있습니다.

```bash
# Python 내장 서버 예시
python3 -m http.server 8080

# 또는 Node npx serve 예시
npx serve .
```
브라우저에서 `http://localhost:8080`으로 접속하여 플레이합니다.
