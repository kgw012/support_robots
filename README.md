# 🤖 서포트 로봇 (Support Robots)

> **무너지는 지하 폐기장, 최소한의 지반 충격으로 고장 난 로봇들을 탈출시켜라!**  
> 알렉스 랜돌프(Alex Randolph)의 전설적인 보드게임 **《리코셰 로봇(Ricochet Robots)》**의 메커니즘을 원작(영감)으로 삼고, 자체 제작한 **'유압식 충격 흡수(로봇 간 완충 충돌 타이 브레이커)'** 시스템을 결합한 비영리 순수 웹 퍼즐 게임입니다.

## 📖 세계관 및 핵심 규칙

버려진 로봇 공장의 지하 깊은 곳, 원인 불명의 시스템 오류로 폐기장 시설이 전면 붕괴하기 시작했습니다. 자세 제어 장치와 마찰력을 상실한 로봇들은 한 번 미끄러지면 **벽이나 다른 로봇에 부딪히기 전까지 스스로 멈출 수 없는 유압 제어 불능 상태**에 빠졌습니다.

1. **직선 슬라이딩 기동**
   * 선택한 로봇을 상·하·좌·우로 조작하면 장애물(외벽, 내부 벽, 중앙 차단 구역, 다른 로봇)을 만날 때까지 직선으로 끝까지 미끄러집니다.
2. **목표 탈출구 매칭 & 방향 전환(Ricochet) 필수 규칙**
   * 목표 탈출구와 **같은 색상의 로봇**을 해당 위치에 정지시켜야 합니다 (다색 소용돌이 탈출구는 모든 로봇 가능).
   * 출발지에서 목적지까지 아무런 충돌 없이 한 번에 직진으로 도달하는 것은 무효이며, **최소 1회 이상 벽이나 로봇에 부딪혀 90도로 방향을 꺾은(Ricochet) 후 도달**해야 탈출로 인정됩니다.
3. **지반 충격 최소화 & 로봇 간 완충(Shock Absorber) 타이 브레이커**
   * 지하 폐기장의 지반은 외벽 충돌 충격에 극도로 취약합니다.
   * **우선순위 1 (최소 이동 횟수):** 컴퓨터가 연산한 '수학적 최단 경로'를 준수하여 조작 횟수를 줄일수록 지반 진동을 최소화한 우수한 기록으로 판정합니다.
   * **우선순위 2 (최다 로봇 간 완충):** 이동 횟수가 같다면, 단단한 외벽 대신 **동료 로봇에 내장된 유압 완충 장치에 부딪혀 충격을 흡수·분산시킨 횟수(`완충`)가 많을수록** 더 높은 점수와 순위를 획득합니다.
   * **우선순위 3 (달성 시간):** 이동 횟수와 완충 횟수가 모두 같다면, 당일 자정 이후 **먼저 기록을 달성한 대원**에게 높은 우선순위를 부여합니다.

## 🎮 게임 모드

* **📅 일일 챌린지 (Daily Challenge):**
  * 한국 시간(KST) 자정마다 새로운 날짜 시드를 기반으로 전 세계 모든 대원에게 동일한 최고 완충 품질의 맵이 출제됩니다.
  * 대원 로그인 후 입장 가능하며, 4개 난이도(`EASY`, `NORMAL`, `HARD`, `HELL`)별로 개인 최고 기록 경신 시 실시간 리더보드에 자동 반영됩니다.
  * 매일 난이도별 1위 대원은 **'최근 10일 명예의 전당'**에 영구 기록됩니다.
* **♾️ 무한 모드 (Infinite Mode):**
  * 원하는 난이도를 선택하여 고품질 퍼즐을 무제한으로 즐길 수 있는 자유 연습/도전 모드입니다.
  * 클리어 시 난이도별 명예 점수(`EASY 10P`, `NORMAL 25P`, `HARD 50P`, `HELL 100P`)가 계정에 영구 적립됩니다.
* **🎓 인터랙티브 튜토리얼 (Tutorial):**
  * 초보 대원을 위해 4단계(기본 미끄러짐 ➔ 90도 꺾임 ➔ 스토퍼 길목 생성 ➔ 실전 종합) 미션과 시각적 제스처 가이드를 제공합니다.

## 🕹️ 조작법 안내

* **📱 모바일 (스마트폰 / 태블릿):**
  * **로봇 선택:** 움직이고 싶은 로봇(빨강/초록/파랑/노랑) 터치
  * **미끄러짐 이동:** 로봇을 상·하·좌·우 원하는 방향으로 **스와이프(드래그)**
  * **되돌리기 / 다시하기:** 하단 좌·우측의 `되돌리기(Undo)` 및 `다시하기(Reset)` 버튼 탭
* **⌨️ PC 키보드 단축키:**
  * **로봇 지정 선택:** `1`(빨강), `2`(초록), `3`(파랑), `4`(노랑)
  * **로봇 순환 선택:** `Tab` (역순: `Shift + Tab`)
  * **미끄러짐 이동:** `방향키 (↑, ↓, ←, →)` 또는 `W, A, S, D`
  * **실행 취소 (Undo):** `Z` (또는 `Ctrl + Z` / `Cmd + Z`)
  * **처음부터 다시하기 (Reset):** `R`
  * **팝업/모달 닫기:** `ESC`

## ⚡ 핵심 엔진 및 최적화 아키텍처

1. **2단계 초고속 BFS 자동 솔버 & 난이도 정밀 검증:**
   * 1단계: 고속 멀티 타깃 BFS(`evaluateBoardCandidates`)로 보드 1판(17개 타깃)의 난이도를 50ms 내 일괄 스캔.
   * 2단계: 8회 이상 후보는 160,000 상태 탐색 정밀 단일 솔버(`solveBoardBFS`)로 팩트체크하여, 10회 이상 수학적 최단 경로가 보장된 퍼즐만 `HELL` 난이도로 출제.
2. **0ms 즉시 진입 사전 생성 (Pre-warming & Smart Caching):**
   * 페이지 진입 시 브라우저 유휴 시간을 활용하여 오늘의 일일 챌린지 4개 난이도를 백그라운드에서 우선 연산(`dailyPuzzleCache`).
   * 무한 모드는 바구니(`curatedBaskets`)에 난이도별 딱 1개씩만 채워두고 연산을 0ms로 즉시 종료하여, **플레이 중 CPU 점유율 0%** 및 배터리 절약을 달성.
3. **타임 슬라이싱 (Time-Slicing) & UI 프리징 차단:**
   * 대규모 경로 탐색 연산 중간마다 `await new Promise(r => setTimeout(r, 0))`로 메인 스레드에 제어권을 양보하여 모바일 ANR(화면 멈춤) 및 터치 지연 방지.
4. **Web Audio 절차적 사이버펑크 사운드 엔진:**
   * 외부 오디오 파일 다운로드 없이 브라우저 Web Audio API로 신시사이저 사운드(8비트 멜로디, 펑키 베이스, 사인파 화음 패드, 6종 SFX)를 실시간 생성.
   * 선행 큐잉 버퍼(850ms)와 네이티브 노드 해제(`osc.onended`)를 결합하여 백그라운드 맵 연산 중에도 BGM 끊김 0% 보장.
5. **원스톱 2중 단방향 암호화 인증 (Supabase Serverless):**
   * 브라우저(`SHA-256`) + DB 내부(`pgcrypto bcrypt`) 2중 해싱으로 비밀번호 원문 노출 차단.
   * Supabase RLS(Row Level Security) 및 `SECURITY DEFINER` RPC 함수 기반의 무결성 보장.

## 🛠️ 기술 스택

* **Frontend:** 순수 HTML5, Vanilla CSS (CSS Grid 16x16), Modern Vanilla JavaScript (ES Modules, 무 프레임워크)
* **Backend & Database:** Supabase (PostgreSQL 15, Row Level Security, Stored Procedures/RPC)
* **Audio Engine:** Web Audio API (Procedural Chiptune/Ambient Synthesizer)
* **Deployment & Hosting:** Vercel (Frontend), Supabase Cloud (Database)
* **Build Tool:** Node.js 기반 자체 빌드 번들러 (`scripts/build.js`)

## 🚀 로컬 개발 및 빌드 방법

### 1. 로컬 개발 서버 실행
Vanilla ES Module 기반이므로 별도의 복잡한 설치 없이 정적 서버로 바로 실행 가능합니다.

```bash
# Python 내장 서버
python3 -m http.server 8080

# 또는 Node npx serve
npx serve .
```
브라우저에서 `http://localhost:8080`으로 접속합니다.

### 2. 프로덕션 빌드
```bash
npm run build
```
`scripts/build.js`가 실행되어 코드 압축 및 식별자 난독화가 적용된 경량 번들이 `dist/` 폴더에 생성됩니다.
